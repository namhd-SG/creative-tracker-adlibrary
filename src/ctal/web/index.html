Mỗi app đối thủ gồm các fanpage chạy quảng cáo cho app đó. Tự tìm page trên Ad Library rồi dán link vào bằng nút ＋ Thêm page.

📌 Cách thêm đối thủ (3 bước)
1Mở Ad Library, chọn All + All ads, gõ tên page/app trong "ngoặc kép".
2Bấm tên page trên một quảng cáo → trang riêng của page mở ra → copy link trên thanh địa chỉ (có view_all_page_id).
3Bấm ＋ Thêm đối thủ (app mới) hoặc ＋ Thêm page trên thẻ app → dán link → ↻ Quét.

＋ Thêm đối thủ

① App→② Page trên Ad Library

Tìm page trên Ad Library (xem khung "Cách thêm đối thủ"), copy link rồi dán vào. Thêm được nhiều page.

    ＋ Thêm page cho

    1. Mở facebook.com/ads/library, chọn All + All ads.
    2. Gõ tên page/app (đặt trong "ngoặc kép" để tìm đúng cụm).
    3. Bấm tên page trên một quảng cáo → copy link trên thanh địa chỉ.
    4. Bấm See ad details trên vài quảng cáo, kiểm link có về đúng app (tránh page trùng tên).
